# M0-T01 Project Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the smallest auditable Electron 43.1.1, electron-vite 5.0.0, React 19.2.7, and TypeScript 5.9.3 project that installs, opens a real development window, and builds successfully.

**Architecture:** Electron main owns the window, an empty sandboxed preload establishes the process boundary, and React renders only a bootstrap status surface. Domain and shared directories remain platform-neutral placeholders; product UI, IPC, editing, file services, and M0-T02 quality tooling are excluded.

**Tech Stack:** Node 24.x, pnpm 11.12.0 via Corepack, Electron 43.1.1, electron-vite 5.0.0, Vite 7.2.6, React/React DOM 19.2.7, TypeScript 5.9.3.

## Global Constraints

- Execute only M0-T01; do not introduce M0-T02 tests, linting, formatting, product UI, file APIs, or editor behavior.
- Keep `packageManager` fixed to `pnpm@11.12.0`; create only `pnpm-lock.yaml`.
- Keep Electron renderer defaults sandboxed with context isolation enabled and Node integration disabled.
- Use exact dependency versions and allow only the audited `esbuild` dependency build script through `pnpm-workspace.yaml` (pnpm 11 no longer reads this setting from `package.json`).
- Do not create a commit because the repository instructions require explicit user authorization.
