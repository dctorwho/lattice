# Typora 1.13.8 Windows 复刻总计划重订实施清单

> **供自动化执行者使用：** 必须使用 `superpowers:executing-plans` 按顺序执行。本文件是一次性变更清单，不是产品总计划，不新增迭代、状态、任务或报告层级。

**目标：** 把项目的权威总计划从“兼容 Typora 1.13.8 的主要功能和工作流”统一重订为“使用独立品牌和独立实现，完整复刻 Typora 1.13.8 在 Windows 10/11 上公开可确认的可观察产品表现”。

**架构：** 保留 M0–M8、源码唯一权威、CodeMirror 6、Electron 沙箱、窄 IPC 和可选 Pandoc。新增一份结构化的版本化证据基线，并扩展现有规划模型与验证器，强制形成“公开证据 → `COMP-*` → 迭代需求 → 测试 → 出口证据”的闭环。

**技术栈：** Markdown、JSON Schema、JavaScript ESM、TypeScript 声明、Vitest、现有规划验证器和 pnpm 11.12.0。

## 全局约束

- 只复刻 Typora 1.13.8 的 Windows 10/11 可观察产品表现。
- 产品名称、图标、Logo、品牌文案、代码、CSS 和可分发资源均独立实现。
- 六套内置主题的视觉效果属于范围，但不得复制 Typora 主题源文件。
- M0 历史测试报告和出口报告不改写；M1 在本次变更中保持 `ready`。
- 继续只使用 M0–M8，不生成 `T01` 一类任务级规划。
- 所有新增或修改的项目文档和报告使用中文。
- 保留当前工作树中已经存在的中文化修改，不覆盖或回退用户改动。
- 未经用户明确授权，不创建 Git 提交、标签、发布或推送。
