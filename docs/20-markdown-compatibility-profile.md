# Markdown 兼容配置

## 1. 基线

默认解析接近 GFM，并加入 Typora 1.13.8 官方文档列出的扩展。该配置定义“显示/导出语义”，不授权保存时重写源码。

## 2. 始终可识别

- 段落、换行、ATX/Setext 标题、引用、列表、任务列表、围栏/缩进代码、分隔线。
- 行内/引用链接、图片、自动链接、强调、粗体、代码、删除线、转义、实体。
- GFM 表格、脚注、YAML Front Matter、`[toc]`。
- 允许的原始 HTML、下划线与媒体标签；安全规则始终生效。

“可识别”不等于默认渲染全部扩展。关闭某特性时保留和显示源码。

## 3. 默认开关

| 特性             | 默认 | 说明                              |
| ---------------- | ---- | --------------------------------- |
| GFM 表格/任务    | 开   | 主流 Markdown 兼容                |
| 脚注/YAML/TOC    | 开   | Typora 核心扩展                   |
| 行内/块公式      | 开   | MathJax 4，本地资源               |
| Mermaid/其他图表 | 关   | 用户显式开启，避免昂贵/非标准渲染 |
| GitHub Alerts    | 关   | 开启后按公开语法解析              |
| Emoji `:name:`   | 开   | 可单独关闭自动补全，源码仍识别    |
| 高亮 `==x==`     | 关   | 防止与普通文本意外冲突            |
| 下标/上标        | 关   | 与转义和数学语法有冲突            |
| 原始 HTML        | 开   | 净化渲染，不执行脚本              |

## 4. 换行和段落

- Enter 创建新段落；Shift+Enter 创建硬换行语义。
- 打开文件不统一尾随双空格、`<br>` 或单换行。
- 自动转换只由明确输入规则触发，已有行不后台修改。

## 5. 列表

- 保留用户 marker（`-/*/+`）和有序编号/分隔符（`.`/`)`）。
- 回车续项采用当前项风格；空项回车退出一级。
- 切换列表类型只修改被选块的必要 markers，不重新编号无关项。
- task checkbox 仅修改 `[ ]/[x]` 范围，大小写策略按原文或统一小写仅限被点击项。

## 6. 表格

- 解析 GFM 管道表格和对齐冒号；保留原分隔线长度、空格和未触及 cell。
- 用户执行结构操作时允许重写受影响行/列，但 SourcePatch 必须列出范围并可 undo。
- cell 内支持行内 Markdown；默认不支持真正换行单元格，HTML `<br>` 保留。

## 7. 链接和锚点

- 保留 inline/reference 定义风格，不自动互转。
- 内部标题 anchor 使用稳定 GitHub 风格 slug 近似并为重复项编号；中英文样例固定黄金测试。
- 本地路径解析考虑文档目录、workspace root 和 `typora-root-url`，显示解析不修改原 URL。
- 点击远程链接需安全协议；编辑状态下优先显示源码而非直接导航。

## 8. 公式

- 支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`，定界符可配置。
- 不闭合/错误 TeX 显示源码与诊断，不吞字符。
- 数学宏来自受控设置或 YAML 数据，不允许加载远程脚本。
- 编号和引用只影响渲染/导出，不回写生成编号。

## 9. 图表

- 围栏语言决定 adapter；`mermaid` 使用 11.13.x。
- 配置指令按 Mermaid 安全规则解析；禁止脚本和任意协议。
- 未知/错误图表保留普通代码块语义。
- 图表结果是投影，不把 SVG 写回 Markdown，除非用户明确“导出/复制为图片”。

## 10. YAML

- 只有文档起始的 `---` 块识别为 front matter。
- 容错解析用于编辑显示，但导出使用 YAML 值前需严格验证。
- 不用表单重写 YAML，不改变键顺序、缩进、注释、引号和多行风格。
- `typora-root-url` 和导出设置仅在相应权限开关开启时生效。

## 11. HTML

- 源码完整保留；预览只展示白名单语义。
- script、事件属性、危险 URL、表单提交、任意 iframe 默认阻断。
- video/audio 需要 controls，资源路径受授权范围限制。
- HTML 解析/净化差异不允许回写或删除原文。

## 12. 不完整语法策略

编辑中结构不完整是正常状态。解析器不能自动补全并保存；投影在不确定时回退原始源码。离开范围后仍不完整，仅显示诊断/源码，不弹阻断对话框。

## 13. Parser 一致性

Lezer 与 markdown-it 对所有黄金 fixture 输出共享的可见语义摘要：块类型、范围、标题、链接、资源、脚注、表格尺寸和扩展节点。差异记录 fixture 与明确处理规则，不能让两个模式各自发展。
