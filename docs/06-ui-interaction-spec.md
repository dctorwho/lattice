# UI 与交互规格

## 1. 总体布局

Windows 首版使用最小化单文档窗口，不引入标签页：

```text
┌──────────────── 标题栏 / 窗口控制 ────────────────┐
│ 菜单入口  侧栏  快速打开  文档标题  源码模式  更多 │
├───────────────┬────────────────────────────────────┤
│ 文件/大纲侧栏 │                                    │
│               │          单栏编辑器                │
│               │                                    │
├───────────────┴────────────────────────────────────┤
│ 状态栏：文件状态 / 字数 / 行列 / 编码 / EOL / 缩放 │
└────────────────────────────────────────────────────┘
```

- 标题栏显示文件名和脏状态，不把完整路径持续暴露在屏幕上。
- 顶部不是富文本 Ribbon。常用结构命令位于菜单、右键和上下文浮层；固定按钮只承载窗口/导航/模式操作。
- 侧栏在文件树、文章列表和大纲之间切换；窄屏自动覆盖，不挤压到无法编辑。
- 编辑区默认居中并限制可读宽度，可在设置关闭最大宽度。

### M0-T05 已实现窗口骨架

- 保留系统窗口边框和系统最小化、最大化、关闭控件；应用内容标题区不伪装系统控件。
- 当前只显示可工作的“切换侧栏”和“关于 Lattice”，不显示打开、保存、编辑、导出或工作区假按钮。
- 侧栏使用真实显示状态并明确“尚未打开工作区”；主内容区明确标注编辑器将在 M1 启用，且没有 `contenteditable`、textarea 或假光标。
- `Ctrl+Shift+L`/`Command+Shift+L` 切换侧栏，`F1` 打开 About；按钮、renderer 右键、快捷键与原生菜单执行相同 command ID。
- About 显示真实应用名称、版本、平台和 IPC 契约版本；失败只显示本地化稳定错误，不显示 request ID、reason、路径或原始异常。
- 关闭 About 会废止仍在途的 AppInfo 展示结果，异步完成不得重新打开对话框。
- 侧栏隐藏、右键菜单 Escape/点击外部、About 关闭后按触发来源恢复焦点；从侧栏右键菜单隐藏侧栏时焦点转移到主区域。
- 右键菜单坐标限制在当前 viewport 内。布局最低 320px，并响应浅色、深色、高对比和减少动画偏好。

## 2. 窗口行为

- 启动行为可选：新文档、恢复上次文件、恢复工作区、打开选择器。
- 从文件树选择文件时在当前工作区窗口切换；从资源管理器打开默认新窗口，可由设置调整。
- 关闭脏文档显示保存、不保存、取消；多个窗口逐一处理。
- 记忆正常/最大化状态、显示器内安全位置、侧栏宽度、缩放和文档滚动锚点。
- 不恢复到已断开的显示器坐标。

## 3. 菜单和固定命令

菜单分类：文件、编辑、段落、格式、视图、主题、帮助。每项绑定 Command Registry。

核心 Windows 快捷键：

| 命令                | 默认键位                                |
| ------------------- | --------------------------------------- |
| 新建/打开/保存/另存 | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| 撤销/重做           | Ctrl+Z / Ctrl+Y                         |
| 查找/替换           | Ctrl+F / Ctrl+H                         |
| 全局搜索            | Ctrl+Shift+F                            |
| 快速打开            | Ctrl+P                                  |
| 源码模式            | Ctrl+/                                  |
| 加粗/斜体/代码      | Ctrl+B / Ctrl+I / Ctrl+Shift+`          |
| 标题 1–6            | Ctrl+1 … Ctrl+6                         |
| 普通段落            | Ctrl+0                                  |
| 链接/图片           | Ctrl+K / Ctrl+Shift+I                   |
| 缩放                | Ctrl+= / Ctrl+- / Ctrl+0                |

最终键位以公开 Typora Windows 快捷键核对；冲突通过快捷键设置解决，不在组件中硬编码。

## 4. 混合编辑显隐规则

- 非活动行隐藏可安全隐藏的强调、链接、图片等标记并呈现样式。
- 选择或光标进入语法范围时显示完整源码；离开且 composition 结束后再隐藏。
- 跨块选择时不替换活动范围为 block widget，避免原生选择断裂。
- IME composition 开始到结束期间冻结活动块投影，不移动 DOM 锚点。
- 语法不完整或解析失败时优先显示源码，不猜测修复。
- 撤销/重做按源码 transaction 工作，装饰重建不进入历史。

## 5. 块组件

- **表格**：非活动时显示表格；聚焦单元格进入可编辑投影，Tab/Shift+Tab 导航，工具条增删行列和对齐。
- **公式**：展示渲染结果；单击/Enter 显示源码编辑区与错误；Esc 返回渲染。
- **图表**：渲染成功显示图；失败显示源码和诊断。渲染不可阻塞输入。
- **代码块**：始终保留可编辑源码，显示语言选择器和复制按钮，不以静态 widget 替换正文。
- **YAML**：文档首部的可折叠源码块；不把 YAML 映射成会重排键的表单。
- **TOC**：只读动态目录，点击跳转；源码仍是 `[toc]`。
- **图片**：显示图片与尺寸/路径操作；选中时可切换到 Markdown 源码。

## 6. 侧栏

- 文件树只显示配置支持的文件；隐藏文件、忽略规则和符号链接策略可配置。
- 文章列表显示文件名、相对路径、修改时间和安全提取的摘要。
- 大纲按标题层级构建，支持平铺/折叠、过滤和跟随当前位置。
- 全局搜索流式返回、可取消；结果显示相对路径、行号和前后文。

## 7. 设置

分类和核心内容：

- 通用：启动、语言、更新、窗口、最近项目。
- 外观：主题、字体、字号、行宽、侧栏、状态栏、跟随系统。
- 编辑器：自动保存、配对、智能标点、拼写、焦点/打字机、缩进。
- Markdown：GFM、公式、图表、Alerts、上下标、高亮、HTML、代码语言。
- 文件：扩展名、树过滤、忽略、排序、外部修改、编码/EOL。
- 图片：插入路径、复制目录、上传器、相对路径。
- 导出：HTML、PDF、图片、Pandoc 和上次导出行为。
- 高级：配置目录、日志、恢复、GPU 参数和重置。

设置项修改必须即时生效或明确显示“重新加载文档/重启应用”，不得静默忽略。

## 8. 可访问性和视觉约束

- 所有图标按钮有 tooltip 与 accessible name；颜色不是唯一状态表达。
- 100%–250% Windows 缩放下不截断关键控件。
- 键盘可遍历菜单、侧栏、设置和上下文工具；焦点返回触发位置。
- 尊重减少动画、高对比度和系统浅/深模式。
- 内置主题为原创 CSS 变量系统；主题不能隐藏保存冲突、安全确认和权限提示等系统 UI。
