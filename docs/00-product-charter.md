# 产品章程

## 1. 产品定义

项目暂用代号 **Lattice**。它是一个本地优先、单栏混合编辑的 Markdown 桌面应用，目标是在不复制 Typora 品牌和私有实现的前提下，对齐 Typora 1.13.8 的公开功能、信息架构和主要操作工作流。

“兼容”具体指：

- 同一 Markdown 文件能够无损打开、编辑和保存。
- 用户能够在单个编辑区内获得即时排版与源码标记按需显隐的体验。
- 菜单、工具栏、侧边栏、状态栏、设置分类和快捷键覆盖等价能力。
- Markdown 扩展、文件管理、图片管理、主题与导出能力有明确等价路径。
- 独立名称、图标、默认主题、插画、文案和发布渠道。

## 2. 成功标准

1. 所有 `COMP-*` 兼容项达到 `passed`，没有未解释的差异。
2. 未编辑文件保存后字节完全相同；编辑文件仅产生与用户操作对应的最小源码变更。
3. 中文 IME、撤销重做、跨块选择、外部文件变更和崩溃恢复连续四周日用无数据丢失。
4. Windows 10/11 x64 安装、卸载、文件关联、命令行打开和导出流程通过发布门禁。
5. 没有严重或高危安全问题，没有从不可信 Markdown/HTML 到 Node 或系统命令的未授权路径。

## 3. 用户与核心场景

- 普通写作者：快速编写 README、博客、笔记和长文。
- 开发者：编辑含代码块、相对链接、HTML 和项目图片的仓库文档。
- 学术用户：使用公式、脚注、引用、表格和 Pandoc 导出。
- 中文用户：依赖稳定的拼音/五笔输入法、全角标点和中英文混排。

主要旅程：打开文件或文件夹 → 在混合模式写作 → 用大纲和搜索导航 → 管理图片与链接 → 保存 Markdown → 导出或交给其他工具继续处理。

## 4. 范围

### 包含

- Windows 桌面应用、单文档窗口、文件夹工作区。
- Markdown 源码模式和单栏混合模式。
- Typora 1.13.8 官方文档公开的 Markdown、文件、图片、主题、导出及可选 Pandoc 导入能力。
- 本地偏好、恢复、最近文件、文件关联和命令行入口。
- 简体中文和英文首发；其他官方语言在兼容收尾阶段扩展。

### 首发不包含

- 账号、云同步、实时协作、在线笔记库、AI 写作、插件市场。
- 手机和平板端。
- 浏览器版。
- Typora 激活、付费、遥测或许可体系的仿制。
- 未在 Typora 1.13.8 中存在的标签页式多文档 UI。

## 5. 法律与品牌边界

- 不反编译、不解包、不复制 Typora 私有源码。
- 不复制名称、图标、默认主题文件、安装包素材和具有识别性的宣传文案。
- 可以实现公开文档描述的行为、标准 Markdown 格式和公开主题接口兼容。
- 发布前进行依赖许可证审计、商标检索和产品界面法律复核。

## 6. 固定基线与变更控制

- 功能基线固定为 2026-07-15 时的 Typora 1.13.8。
- 开发期间 Typora 新版本不自动进入范围；新增能力必须建立单独变更提案。
- 无法通过官方资料确认的细节标记为 `documented-gap`，不得声称完全一致。
