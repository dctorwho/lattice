## 参数矩阵

- `CMD-M3`：无文档、clean/dirty/只读、无/有选区、无/有工作区、搜索运行中、对话框打开；四种入口。
- `WSROOT-M3`：普通/中文/空格/长路径/UNC 根；隐藏文件、`.gitignore`、自定义忽略、大小写碰撞、junction/symlink 环和逃逸。
- `FILEOP-M3`：普通/Unicode/保留名/大小写仅变化/长路径；目标存在、只读、权限拒绝、文件占用、跨卷、用户取消。
- `OUTLINE-M3`：ATX/Setext、重复标题、h1→h4 跳跃、代码内假标题、HTML、10MB 文档、编辑前后 selection 锚点。
- `OPEN-M3`：中文拼音不要求、大小写、路径分隔符、连续字符/模糊匹配、同分排序、丢失最近项。
- `SEARCH-M3`：中文、正则关闭时元字符、引号/分号/`&`、大结果、二进制、忽略、无权限、脏文档与磁盘同路径。
- `SESSION-M3`：单/双显示器、显示器断开、负坐标、不同 DPI、最大化、损坏 session、最近路径消失。

## 证据与停止条件

保存生成器种子、文件树快照、sidecar 参数数组/退出状态、操作前后目录清单和 P50/P95。越权访问、永久误删、搜索取消后进程残留、10,000 文件任务阻塞输入或窗口恢复到不可见区域均阻断 M3。
