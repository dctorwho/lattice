# Task Model v1 Historical Archive

This directory preserves the repository's former task-level planning model for
provenance only. Every `Mx-Tnn` identifier in this archive is historical: it is
never selectable work, never an active dependency or status node, and never an
acceptance owner. Active work is selected only from `iterations/state.json`.

The entire archive is excluded from active planning gates. Its files must not
be used by planning validation, dependency calculation, task selection, or
iteration status transitions. Historical wording is intentionally preserved;
Git history remains the authority for changes before this move.

The source commit column records the exact final commit returned before the
move by `git log -1 --format=%H -- <original-path>`. Every listed source commit
is an ancestor of `main`.
