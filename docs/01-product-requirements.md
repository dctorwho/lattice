# 产品需求规格

需求使用稳定 ID。删除需求时保留 ID 并标记废弃，禁止重新编号。每项要求必须通过 [`REF-*` 公开证据](22-typora-1.13.8-windows-evidence-baseline.md)、`COMP-*` 复刻验收项、所属迭代和测试证据形成闭环；资料不足不能被当作已经实现。

## 1. 文档生命周期

- **DOC-001 新建**：创建未命名 Markdown 文档；第一次保存必须选择位置和扩展名。
- **DOC-002 打开**：支持文件选择器、拖放、资源管理器关联、命令行和最近文件入口。
- **DOC-003 无损保存**：未编辑保存字节完全一致；编辑保存保留未触及的编码、BOM、行结束符和源码布局。
- **DOC-004 原子保存**：写入失败、崩溃或权限错误不得损坏原文件。
- **DOC-005 另存为**：保留当前内容并切换会话路径；原文件不再被后续保存修改。
- **DOC-006 外部变化**：检测修改、删除和重命名；脏文档不得静默重载或覆盖。
- **DOC-007 自动保存**：按设置保存已命名文档；外部冲突时暂停并提示。
- **DOC-008 恢复**：崩溃或强制退出后恢复未保存内容，可逐个丢弃或另存。
- **DOC-009 编码**：首版读写 UTF-8、UTF-8 BOM、UTF-16LE/BE BOM；未知编码只读打开，禁止猜测覆盖。
- **DOC-010 大文件降级**：超过阈值时进入源码优先模式，暂停昂贵的图表、公式和拼写检查。

## 2. 编辑器

- **EDT-001 单栏混合编辑**：同一编辑区呈现排版结果，光标附近按需显示 Markdown 标记。
- **EDT-002 源码模式**：显示完整 Markdown 源码和语法高亮。
- **EDT-003 状态连续**：两种模式共享文本、选择、滚动位置、折叠状态和撤销历史。
- **EDT-004 最小补丁**：格式化、表格、公式等操作只修改目标源码范围。
- **EDT-005 撤销重做**：输入、结构命令、粘贴和图片源码修改纳入一致历史；磁盘副作用另有事务日志。
- **EDT-006 IME**：中文、日文、韩文组合输入期间不重绘活动块，不拆分撤销单元。
- **EDT-007 输入规则**：支持标题、引用、列表、任务、代码块、表格、分隔线、数学块和 YAML 的快捷创建。
- **EDT-008 自动配对**：括号、引号、反引号、强调符和数学定界符按设置工作。
- **EDT-009 查找替换**：大小写、全词、正则、向前/向后、全部替换，并保持可撤销。
- **EDT-010 复制粘贴**：复制可输出富文本、Markdown、HTML、纯文本；粘贴支持智能 HTML 转 Markdown和纯文本模式。
- **EDT-011 模式**：焦点模式、打字机模式、只读查看和缩放。
- **EDT-012 辅助编辑**：拼写检查、自动链接、Emoji 补全、智能标点、行/段上移下移。
- **EDT-013 字数统计**：显示全文字符、词、行、阅读时间；有选区时同时显示选区统计，规则对中英文稳定。
- **EDT-014 行级剪切复制**：无选区时按设置复制/剪切当前行，行为可撤销且不误吞尾行换行。

## 3. Markdown 复刻与格式兼容

- **MD-001 基础块**：段落、ATX/Setext 标题、引用、有序/无序列表、任务列表、围栏/缩进代码、分隔线。
- **MD-002 行内语法**：强调、加粗、删除线、代码、链接、图片、自动链接、转义和实体。
- **MD-003 扩展行内**：Emoji、行内公式、下标、上标、高亮、下划线。
- **MD-004 表格**：GFM 表格、对齐、增删/移动行列、调整列宽、单元格导航和多列对齐。
- **MD-005 学术**：脚注、引用链接、内部锚点、数学编号和 TeX 引用。
- **MD-006 元数据**：YAML Front Matter 容错编辑，原始键顺序和格式不被无关操作改变。
- **MD-007 目录与提醒**：`[toc]`、GitHub 风格 Alerts/Callouts。
- **MD-008 代码**：语言选择、语法高亮、复制全部、自动缩进和长行滚动。
- **MD-009 公式**：MathJax 4，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 及可配置宏。
- **MD-010 图表**：Mermaid 11.13、Sequence 和 Flowchart 兼容入口；失败时展示源码与诊断，不破坏内容。
- **MD-011 HTML**：安全渲染允许的行内/块 HTML、视频和嵌入；脚本永不在编辑器权限域执行。
- **MD-012 GFM 语义**：默认接近 GitHub Flavored Markdown，同时保留 Typora 文档列出的扩展和兼容设置。

## 4. 文件夹工作区

- **WS-001 打开文件夹**：将文件夹设为窗口工作区。
- **WS-002 文件树/列表**：树形与文章列表视图，过滤支持的文本文件，保持展开和选中状态。
- **WS-003 文件操作**：新建、重命名、移动、删除、在资源管理器显示；危险操作二次确认。
- **WS-004 大纲**：层级/平铺、折叠、搜索、当前标题跟随和点击跳转。
- **WS-005 快速打开**：按文件名与相对路径模糊匹配。
- **WS-006 全局搜索**：目录文本搜索、结果上下文、高亮、取消、忽略规则和点击定位。
- **WS-007 排序**：名称、修改时间、创建时间，自然排序，文件夹混排选项。
- **WS-008 最近项目**：最近文件和文件夹，丢失路径可移除。

## 5. 图片与资源

- **IMG-001 插入来源**：文件选择、拖放、剪贴板和远程 URL。
- **IMG-002 路径策略**：相对、绝对、复制到配置目录、始终添加 `./`、YAML `typora-root-url`。
- **IMG-003 文件操作**：移动、重命名、删除、重新加载，并同步最小修改 Markdown 链接。
- **IMG-004 上传**：自定义命令和受支持上传器适配器；命令参数结构化传递，默认不使用 shell。
- **IMG-005 查看与复制**：缩放、打开原图、复制图片/路径、下载远程图片。
- **IMG-006 事务一致性**：撤销源码修改时明确处理已复制文件；删除原文件必须确认且可恢复。

## 6. 导入、导出与打印

- **EXP-001 HTML**：带当前/指定主题的独立 HTML，可选大纲与自定义 head/body。
- **EXP-002 纯 HTML**：无主题样式的语义 HTML。
- **EXP-003 PDF**：纸张、方向、边距、缩放、背景、主题、页眉页脚、顶级标题分页和大纲。
- **EXP-004 图片**：整文档或选区，比例、质量、背景和主题。
- **EXP-005 Pandoc**：可配置路径，支持 DOCX、ODT、RTF、EPUB、LaTeX 等；缺失时给出诊断。
- **EXP-006 导出记忆**：重复上次设置、使用上次目标覆盖，并在覆盖前验证路径。
- **EXP-007 每文件设置**：经用户显式允许后读取 YAML 导出设置；默认不执行任意参数或脚本。
- **EXP-008 打印**：调用系统打印，预览样式与 PDF 渲染契约一致。
- **EXP-009 Pandoc 导入**：Pandoc 可用时，从 DOCX、RTF、EPUB、LaTeX/TeX、RST、Org、MediaWiki/DokuWiki、Textile 和 OPML 导入为新的未命名 Markdown 会话；导入永不覆盖源文件，转换警告可见，失败或取消不创建部分会话。Pandoc 缺失时核心 Markdown 打开与导出不受影响。

## 7. 外观、命令与设置

- **UI-001 窗口结构**：独立实现并复刻 Typora 1.13.8 Windows 的标题栏、应用菜单/工具栏、可折叠侧栏、中央编辑器、状态栏及公开状态反馈。
- **UI-002 命令统一**：菜单、按钮、右键和快捷键共用 Command Registry。
- **UI-003 主题**：使用独立 CSS、字体策略和自有资源重现六套内置主题效果，支持明暗模式、跟随系统、自定义 CSS 目录和主题热重载。
- **UI-004 Typora 主题适配**：复刻公开 CSS 主题约定的可观察行为，但不复制或捆绑 Typora 主题源文件和品牌资源。
- **UI-005 设置分类**：通用、外观、编辑器、Markdown、文件、图片、导出、高级。
- **UI-006 快捷键**：Windows 默认键位与 Typora 公开键位对齐，可通过配置覆盖并检测冲突。
- **UI-007 国际化**：简体中文、英文首发；字符串、菜单和日期可本地化。
- **UI-008 无障碍**：键盘可达、可见焦点、语义标签、屏幕阅读器名称和高对比度。

## 8. 桌面集成

- **OS-001 单实例与窗口路由**：根据设置在当前窗口或新窗口打开文件。
- **OS-002 文件关联**：`.md`、`.markdown`、`.mdown`、`.mkd`、`.txt`、`.qmd` 可配置关联。
- **OS-003 命令行**：接受文件、文件夹和定位参数，不存在文件可按设置创建。
- **OS-004 窗口状态**：恢复尺寸、位置、最大化、侧栏宽度、最近工作区和编辑位置。
- **OS-005 安装卸载**：NSIS 安装包，卸载可选择保留用户设置和主题。
- **OS-006 更新**：自用阶段关闭；公开发布后启用签名更新和稳定/预览通道。

## 9. 非功能需求

- **NFR-001 数据安全**：任何静默数据损坏均为 P0。
- **NFR-002 响应**：普通输入 P95 事务到绘制低于 30ms；组合输入不得明显卡顿。
- **NFR-003 启动**：参考机器冷启动到可输入低于 2.5 秒。
- **NFR-004 大文档**：5MB 普通 Markdown 可在 3 秒内打开；10MB 在降级模式可编辑。
- **NFR-005 大目录**：10,000 个文件的树构建和搜索不阻塞编辑线程，可取消。
- **NFR-006 内存**：空窗口稳定后目标低于 250MB；大文档和图表按预算记录。
- **NFR-007 离线**：核心编辑与原生导出不依赖网络或 CDN。
- **NFR-008 可测试性**：时钟、文件系统、对话框、进程和 watcher 均可替换测试实现。
- **NFR-009 可观测性**：本地结构化日志，不记录文档内容、完整路径或剪贴板正文。
- **NFR-010 兼容性**：Windows 显示缩放 100%–250%、多显示器、触控板和常见中文 IME。
