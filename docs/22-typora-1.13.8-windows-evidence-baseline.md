# Typora 1.13.8 Windows 公开证据基线

## 1. 目的

本文件是 Typora 1.13.8 Windows 复刻要求的活跃证据台账。它记录公开资料中能够确认的用户可观察界面和行为，并把来源追踪到全局需求、复刻验收项、所属迭代和测试用例。

本文件不复制 Typora 私有代码、主题文件、品牌素材或整篇外部内容。公开页面是持续更新的活文档，每条记录必须独立说明为什么适用于 1.13.8。

## 2. 来源优先级

1. Typora 1.13.8 官方发布记录；
2. 能确认适用于 1.13.8 的官方文档和截图；
3. 能确认版本的公开视频或可信评测；
4. 由多个来源交叉验证、但版本不能完全确认的资料；
5. 单一且无法验证的资料只能登记为 `证据不足`。

## 3. 状态与差异规则

- `未实现`：证据已确认，但所属迭代尚未完成实现和验收；
- `已实现`：实现已经存在，但仍以所属迭代出口证据决定是否最终通过；
- `存在差异`：当前实现与证据描述不一致，所属迭代不得通过；
- `证据不足`：无法可靠确认版本或行为，不能凭推测标记为通过；
- M8 最终通过时，已知复刻差异必须为零，影响核心功能、数据安全、主要交互或主要视觉的 high/medium 证据缺口必须为零。
