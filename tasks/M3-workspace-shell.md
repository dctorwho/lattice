# M3：工作区与桌面壳

必读：[UI 交互](../docs/06-ui-interaction-spec.md)、[命令清单](../docs/21-command-menu-inventory.md)、[公共契约](../docs/15-public-contracts.md)、[用户旅程](../docs/19-user-journeys.md)、[安全](../docs/05-data-safety-and-security.md)、[M3 测试用例](../docs/test-cases/M3-workspace-shell.md)。

## M3-T01 完整窗口与命令菜单

- 依赖：M2-T10
- 需求：UI-001、UI-002、UI-006
- 交付：文件/编辑/段落/格式/视图/主题/帮助菜单、顶部固定导航按钮、上下文菜单和状态同步；只显示已实现命令。
- 验证：UI-021..045，四种入口同 command ID、启用/选中一致、快捷键冲突检测。

## M3-T02 工作区授权与枚举

- 依赖：M3-T01
- 需求：WS-001、WS-002；风险 R-008
- 交付：选择文件夹、持久授权范围、fast-glob 枚举、支持扩展/隐藏/忽略/符号链接策略、可取消任务。
- 验证：WS-001..018、SEC 路径逃逸和 symlink；10,000 文件初始枚举不阻塞 editor。

## M3-T03 文件树、文章列表和文件操作

- 依赖：M3-T02
- 需求：WS-002、WS-003、WS-007
- 交付：树/列表、展开/选中、自然排序、新建/重命名/移动/回收站删除/资源管理器显示；错误可恢复。
- 验证：WS-019..045，Unicode/长路径/大小写/占用/权限；危险操作人工确认。

## M3-T04 大纲

- 依赖：M3-T01
- 需求：WS-004
- 交付：从当前增量语法树构建层级/平铺大纲、折叠、过滤、当前标题跟随、点击定位；不单独重新解析全文。
- 验证：WS-046..062，重复标题、层级跳跃、Setext、超长文档、编辑后增量更新。

## M3-T05 快速打开

- 依赖：M3-T02
- 需求：WS-005
- 交付：文件名/相对路径模糊匹配、键盘选择、结果排序、取消和最近项；不索引工作区外路径。
- 验证：WS-063..075，中文、大小写、路径分隔符、10,000 文件响应。

## M3-T06 全局搜索

- 依赖：M3-T02
- 需求：WS-006；风险 R-005
- 交付：打包 ripgrep sidecar、参数数组 spawn、流式结果、上下文、高亮、取消、忽略规则；活动脏文档结果合并去重。
- 验证：WS-076..105、SEC shell 元字符；大结果限制、二进制跳过、取消终止进程。

## M3-T07 最近项目与窗口会话

- 依赖：M3-T03、M3-T04、M3-T05、M3-T06
- 需求：WS-008、OS-001、OS-004
- 交付：最近文件/文件夹、启动策略、窗口尺寸/显示器安全恢复、侧栏宽度、活动文件、滚动锚点；路径丢失清理。
- 验证：OS-001..020，断开显示器、多窗口、崩溃后恢复、无正文进入 session.json。

## M3-T08 工作区门禁

- 依赖：M3-T07
- 需求：COMP-010..013、NFR-005
- 交付：10,000 文件性能报告、文件操作故障矩阵、菜单/键盘/侧栏可用性报告。
- 自动验证：check、integration、E2E、security、workspace performance。
- 人工门禁：真实大仓库、OneDrive/同步目录、长路径、文件回收站、搜索取消和多显示器恢复；通过后解锁 M4-T01。
