# Lattice brand assets

These are original Lattice project assets, authored on 2026-08-02. They do not
copy Typora, Electron, or another product's brand material.

## Geometry and palette

`lattice-icon.svg` is a 256×256 square with a `#161A2B` background. Four
separate rounded lattice tiles sit at `(40,44)`, `(120,44)`, `(40,124)`, and
`(120,124)`, each measuring `64×64` with a radius of `16`. The tiles use
`#8B5CF6`, `#A78BFA`, `#C4B5FD`, and `#8B5CF6`; a white `#FFFFFF`, 10-pixel
diagonal source line runs from `(48,208)` to `(208,48)`.

The source is project-authored SVG geometry only: it contains no font,
embedded bitmap, remote reference, or copied metadata.

## Reproducible generation

Run the generator from the repository root:

```powershell
node scripts/assets/build-lattice-icon.mjs
node scripts/assets/build-lattice-icon.mjs --check
```

The script uses only Node built-ins (`node:crypto`, `node:fs`, and `node:zlib`)
to generate a fixed RGBA PNG with deterministic chunk CRC32 and compression,
then embeds that PNG as the ICO's sole 256×256 image. It accepts no output path
arguments and resolves its fixed destinations only as repository-relative
paths. Generated bytes contain no timestamps.
